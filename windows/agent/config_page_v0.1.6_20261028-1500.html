Tab2Monitor: nomi e ventole

Controllo ventole (solo scheda madre): BIOS = nessun intervento; fissa = percentuale costante; curva = punti gradi:% sulla temperatura scelta, es. 40:25, 60:45, 75:80, 85:100. Si può scendere fino a 0% (ventola ferma); 100% se la temperatura non si legge o la CPU supera 90 °C; se il server si ferma le ventole tornano al BIOS.

Dai un nome a ventole, temperature e componenti, e scegli per ogni ventola la temperatura da mostrarle accanto sul tablet. Campo vuoto = nome originale.
